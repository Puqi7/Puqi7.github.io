\section{Research Interests}
My research focuses on \textbf{\textit{human-centered multi-robot systems}}: I model \textbf{\textit{human attention and behavior}}, and use these models to design \textbf{\textit{adaptive interfaces and shared autonomy}} for real-world robot teams in high-stakes settings.

\section{Research Positions}
\position{George Mason University}{Ph.D.\ Student, Department of Computer Science}{09/2025--present}{%
  Human-Centered Multi-Robot Systems\\
  Advisor: Prof.\ David Porfirio}
\begin{itemize}
\item Developed Attune, a self-annotation tool combining robot-camera video, eye tracking, and AI-assisted annotation to characterize operator attention profiles during multi-robot supervision (UIST 2026).
\item Model how robot motion, visual information, and task context shape human attention over time.
\item Design adaptive interfaces and shared autonomy that preserve operator control, including social behavior during robot teleoperation.
\end{itemize}
